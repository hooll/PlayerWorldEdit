# PlayerWorldEdit

## 构建发行版本

发行版本用于正常使用, 不含 TabooLib 本体。

```
./gradlew build
```

## 构建开发版本

开发版本包含 TabooLib 本体, 用于开发者使用, 但不可运行。

```
./gradlew taboolibBuildApi -PDeleteCode
```

> 参数 -PDeleteCode 表示移除所有逻辑代码以减少体积。

## 性能约定

插件跑在 Folia 系核心 (Lophine) 上, 全服玩家共用区域线程, 所以**批量操作必须按下面的方式来**,
后面的新功能也一样:

1. **不让一条区域线程长时间干活**: 区域类读写统一走 `runOnChunkThreads`(按区块拆开、沿 Y 轴切片),
   不要自己在一条任务里跑完整块选区。
2. **全服每 tick 有预算**: 批量改方块前先 `EditBudget.tryConsume(数量)`, 领不到就下一 tick 重试。
   节流参数写在 `settings.yml`, 代码里必须留默认值 —— TabooLib 不会覆盖已存在的配置文件,
   服上的老配置不会有新键。
3. **玩家线程只做轻活**: 序列化、压缩、写库、大循环一律丢异步线程; 回到玩家线程只做提示和记账,
   要能在几毫秒内做完。
4. **定时任务按区块/实体合并**: 不要每个点、每个实体各提交一个区域任务(选区粒子以前就是这样,
   一秒钟几千个任务)。
5. **大操作要有反馈 + 防重入**: 跨多个 tick 的操作要有"正在处理"提示, 并用 `beginEdit`/`endEdit`
   拒绝同一玩家的并发操作。
6. **改完要验证**: 本地 `./gradlew build` 必须通过; 动到编辑链路时, 在服上用大选区
   (100×100×50 起步) 实测一次 TPS。
