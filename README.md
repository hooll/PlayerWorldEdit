# PlayerWorldEdit

给生存服玩家用的建筑工具。玩家先把方块存进材料背包，再用这些材料批量填充、替换或粘贴建筑，不需要给玩家 WorldEdit 管理权限。

支持选区填充、替换、围墙、圆柱、扩展与收缩、移动建筑，以及复制、旋转、镜像和粘贴。常用操作可以在游戏内菜单完成。

## 安装

1. 安装适用于服务端版本的 **WorldEdit**。
2. 将 PlayerWorldEdit 的发行版 jar 放入 `plugins` 文件夹。
3. 重启服务器，检查控制台是否正常加载。
4. 管理员执行 `/pwe tool` 领取工具，先在测试区域试用。

插件包含 Folia 区域线程调度。不同核心、WorldEdit 版本和领地插件组合仍需在自己的服务器上测试；不要仅凭插件成功加载就认为所有功能都已兼容。

可选插件：

| 插件 | 用途 |
|---|---|
| Dominion | 领地权限检查 |
| Residence | 领地权限检查 |
| WorldGuard | 区域权限检查 |
| CoreProtect | 记录以玩家身份进行的 WorldEdit 编辑 |

不装领地插件时，本插件不会替你限制玩家的编辑范围。当前领地接入仍有待修问题，见文末的注意事项。

## 玩家怎么用

1. 管理员发放创世神镐。
2. 玩家执行 `/pwe pack`，点击「添加材料」，放入方块后关闭界面。
3. 手持创世神镐，左键选择第一个点，右键选择第二个点。
4. 潜行并右键打开操作菜单，选择填充、替换等功能。

选区默认用半透明玻璃框显示给玩家本人，重新选点会刷新。填充和替换后保留选区，不必每次重新选择。

圆柱不需要选区，生成位置以玩家所在位置为中心。菜单里的半径和高度可以用按钮增减。

### 材料背包

- 左键取出 1 个，右键取出 10 个，Shift + 右键取出 64 个。
- 添加材料时，带自定义名称或描述的物品、非方块物品会退回。
- 材料背包按方块种类计数，不是用来存放特殊物品的仓库。
- 正常退出和关服时会保存材料数据。请正常停服，不要直接结束进程；当前缓存保存方式不保证异常退出时的交易完整性。

### 材料怎么算

| 操作 | 消耗 |
|---|---|
| 填充 | 按选区体积扣除所选材料 |
| 替换 | 按匹配到的方块数量扣除新材料 |
| 围墙、圆柱 | 按生成范围内的方块数量扣除材料 |
| 扩展 | 按最外层复制出去的方块，逐种扣除材料 |
| 移动 | 按源建筑的非空气方块，逐种扣除材料 |
| 粘贴 | 按粘贴内容的非空气方块，逐种扣除材料 |
| 复制、旋转、镜像、预览 | 不消耗材料 |

空气不消耗材料。收缩和移动清掉的源方块不会自动返料；撤销按记录返还材料。

替换匹配的是方块状态，不只是名称。例如 `/pwe replace oak_log stone` 匹配默认朝向的橡木原木，不会把所有朝向的原木都换掉。

## 命令与权限

普通操作使用 `PlayerWorldEdit.Use`，默认允许使用。若不想开放给所有玩家，请用权限插件取消普通玩家的该权限，再按玩家组授予。

| 命令 | 说明 |
|---|---|
| `/pwe` | 查看帮助 |
| `/pwe pack` | 打开材料背包 |
| `/pwe set <方块>` | 填满选区；使用 `air` 清空 |
| `/pwe replace <原方块> <新方块>` | 替换选区中匹配的方块 |
| `/pwe wall <方块>` | 沿选区四周生成墙，不含顶和底 |
| `/pwe cyl <方块> <半径> [高度]` | 以玩家位置为中心生成实心圆柱 |
| `/pwe hcyl <方块> <半径> [高度]` | 生成空心圆柱，内部不动 |
| `/pwe expand [格数]` | 朝视线方向复制选区最外层，并扩展选区 |
| `/pwe contract [格数]` | 朝视线方向收缩选区，移除的层清成空气 |
| `/pwe move [格数]` | 朝视线方向移动建筑，选区位置不变 |
| `/pwe copy` | 复制选区到个人剪贴板 |
| `/pwe rotate <角度>` | 水平旋转剪贴板，支持 90、180、270 度 |
| `/pwe flip [方向]` | 镜像剪贴板；省略方向时按水平朝向判断 |
| `/pwe paste` | 直接粘贴，不经过预览确认 |
| `/pwe paste preview` | 显示粘贴范围和预计用料，不写方块 |
| `/pwe undo [次数]` | 撤销最近的操作 |
| `/pwe id` | 查看手中物品的 ID |

圆柱高度默认 1；扩展、收缩、移动和撤销的数量默认 1。圆柱半径与高度范围为 1–256，扩展、收缩和移动格数范围为 1–100。

镜像方向：`n` 北、`s` 南、`e` 东、`w` 西、`u` 上、`d` 下、`me` 当前水平朝向。

管理员命令需要 `PlayerWorldEdit.Admin`，默认仅 OP：

| 命令 | 说明 |
|---|---|
| `/pwe tool` | 领取创世神镐 |
| `/pwe reload` | 重载配置与语言文件 |

### 复制与粘贴

复制时会记住玩家与建筑的相对位置。粘贴时，复制时的原点对齐到玩家当前脚下。

- 剪贴板里的空气也会粘贴，可能清掉目标位置已有的方块。
- 剪贴板只在内存中，退出后清空，不会跨登录保存。
- 菜单里的粘贴按钮第一次点击是预览，10 秒内在同一目标范围再次点击才执行。
- 命令 `/pwe paste` 始终直接执行。先看落点请用 `/pwe paste preview`。
- 移动的目标超出世界高度或世界边界时，整次操作取消；圆柱、扩展和粘贴则会裁掉不能写入的部分。

## 服主常用配置

配置在 `plugins/PlayerWorldEdit/settings.yml`，下列选项位于 `world-edit` 节点：

```yaml
world-edit:
  region-display: true
  region-display-material: WHITE_STAINED_GLASS
  region-display-owner-only: true
  region-display-duration: 0
  undo-limit: 10
  blocks-per-tick: 20000
  coreprotect-logging: true
```

| 选项 | 说明 |
|---|---|
| `region-display` | 使用玻璃框显示选区；关闭后改用粒子 |
| `region-display-material` | 选区框材质 |
| `region-display-owner-only` | 是否只让选区主人看到玻璃框 |
| `region-display-duration` | 显示秒数；0 表示不自动消失 |
| `undo-limit` | 每名玩家保留的撤销记录数，默认 10 |
| `blocks-per-tick` | 方块处理预算；调小会延长大操作的耗时，不代表固定的性能保证 |
| `coreprotect-logging` | 编辑时是否带上玩家身份，供 CoreProtect 等记录插件使用 |

创世神镐的材质、名称、描述和模型数据在 `world-edit.tool` 下修改。材料背包界面文案在 `material-pack-gui` 下修改，提示文本在 `lang/zh_CN.yml` 中修改。

改完执行 `/pwe reload`。工具外观改动需要重新领取工具；重载会收掉当前显示的选区框，重新选点后再显示。

## 数据与备份

撤销记录存放在：

```text
plugins/PlayerWorldEdit/undo/<玩家UUID>/
```

更新插件前，备份世界和整个 `plugins/PlayerWorldEdit` 目录，不要只备份 jar。大选区会占用更多内存和撤销文件空间，目前没有选区体积上限。

**撤销不能替代世界备份。** 撤销记录里会保存方块本身以及方块的实体数据（箱子里的物品、告示牌文字等），所以撤销、复制、粘贴、搬运都会带上容器内容与牌子文字。仍有两点要知道：轮换和镜像只转动方块朝向，不会改变容器里物品的摆放或牌子上的文字（与 WorldEdit 一致）；生物、掉落的物品、画框这类**实体**不在快照范围内，撤销只还原方块。另外，早期版本留下的撤销记录里没有实体数据，撤销这些旧记录时容器内容无法还原。

## 注意事项

请先在测试服确认常用操作，再向普通玩家开放。当前没有真实服务端的完整验证，不建议直接用于无法回档的世界。

- 领地检查依赖保护插件的实际版本，不要将它作为唯一保护边界。使用 WorldGuard 多边形（非矩形）区域的服务器：与这类区域相交的编辑会被明确拒绝，即使你在那里有完整建造权限；区域叠加过于复杂、Residence 区域数据无法读取时也会拒绝。
- 材料包只接受与同材质全新物品等价的普通方块。带容器内容、PDC、自定义模型等额外数据的物品应原样退回，不会按材质收走。不同服务端的组件判定和满背包退物仍需在测试服确认。
- 材料库和玩家背包存档没有共同事务。异常关服时，存入可能同时恢复原物品与材料余额，也可能丢失尚未完成的存入；提现可能已扣材料却没有发出或保存物品。交易阶段与原物记录保存在 `material-transactions/`，结果不明时会暂停该账号的材料交易，重启后仍需人工核对。这些记录不是自动恢复或防复制保证，请保留文件，不要直接重试或删除记录。

  账号被暂停后的人工核对方法：打开 `material-transactions/`，文件名开头是玩家 UUID；`state` 为 `UNKNOWN`、`PREPARED`，或方向为 `WITHDRAW` 且 `state` 为 `COMMITTED`（已扣材料但没确认发出）的记录都需要核对——对照文件里的物品记录与该玩家的材料库余额，人工处理完成后删除对应文件并重启服务端，暂停即解除。已完成交易的记录会被自动删除，目录不会无限增长。
- 编辑中断后，提交状态无法确认的单格尝试可能暂时占用材料；成功撤销后再退还对应成本。请先确认撤销结果，不要将失败提示理解为世界完全没变。
- 停用插件会停止接收新编辑并等待在途切片收尾。卡死的写入线程不能安全强杀，持久化失败也不能保证在进程退出前补救；这种情况下日志会点名退料可能未落库的玩家，需要人工核对。停用未排空后再次启用会被拒绝（日志说明原因），请完整重启服务端，不要在未排空状态下热启用。Folia 上停用期间的显示体清理仍需实测。
- 选区与形状没有体积上限，大选区会增加内存、撤销文件和数据库开销。交易记录也需要定期备份和核对后归档。

## 自行构建

构建环境使用 JDK 21，在项目目录执行：

```sh
./gradlew build
```

发行版 jar 位于 `build/libs`。服主正常安装使用发行版即可，不需要单独安装 TabooLib。
