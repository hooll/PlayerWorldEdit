# PlayerWorldEdit

生存服用的创世神插件: 玩家用自己攒的方块材料去填充/替换选区, 材料不够就改不动,
把 WorldEdit 的能力做成"要花材料"的生存玩法。插件跑在 Folia 系核心上。

依赖: **WorldEdit**(官方版, 必需) / **Dominion**(可选, 领地保护)

## 功能

### 创世神镐

- `/pwe tool` 领取(需要 `PlayerWorldEdit.Admin`, 默认 OP)
- 左键点选点 1, 右键点选点 2, 两个点必须在同一个世界, 选完在聊天栏显示坐标和选区方块数
- 选区用一个半透明玻璃盒子标出来, 只显示给自己看, 默认一直显示到选区被清除或退出登录;
  想让它到点自动消失就把 `region-display-duration` 改成秒数 (材质、是否只给自己看也能在配置里改)
- 填充/替换**成功后保留选区**(和 WorldEdit 的手感一致), 想接着改同一块地方不用重新选点;
  换地方直接重新点两个点就行
- **潜行 + 右键**打开快捷操作菜单

### 花材料才能改

- 填充按选区方块数扣材料, 替换按**实际替换掉的数量**扣材料
- 撤销会把扣掉的材料原样还回来
- 空气不消耗材料(用来清空区域)
- 材料不足、方块名无效、没选完区域、选区跨世界, 都有对应提示

### 材料背包

- `/pwe pack` 打开, 分页显示
- 左键取 1 个 / 右键取 10 个 / shift + 右键取 64 个
- 界面中间的「添加材料」打开一个空箱子, 把方块放进去, 关掉界面就自动收进背包;
  带自定义名字或描述的物品、以及非方块物品会原样退回
- 材料存在玩家数据里, 重登不丢
- 材料包在玩家在线期间缓存在内存里(退出登录 / 关服时落盘), 所以取物、扣材料不再每次都读写数据库

### 快捷操作菜单

潜行 + 右键创世神镐打开:

| 槽位 | 内容 | 作用 |
|---|---|---|
| 中间 | 选区信息 | 显示已选区域有多少方块 |
| 左 | 材料背包 | 打开材料背包 |
| 中左 | 设置方块 | 从材料背包里挑一个方块填满整个选区; 第一格「空气」= 清空 |
| 中右 | 替换方块 | 先选原方块, 再选新方块 |
| 右 | 撤销 | 撤销最近一次操作并返还材料 |

方块选择界面只列出材料背包里有的方块 + 空气, 物品名跟随客户端语言(中文客户端显示中文名)。

### 命令

| 命令 | 说明 | 权限 |
|---|---|---|
| `/pwe` | 命令帮助 | `PlayerWorldEdit.Use` |
| `/pwe pack` | 打开材料背包 | `PlayerWorldEdit.Use` |
| `/pwe set <方块>` | 用指定方块填充选区 | `PlayerWorldEdit.Use` |
| `/pwe replace <原方块> <新方块>` | 替换选区内的方块 | `PlayerWorldEdit.Use` |
| `/pwe undo [次数]` | 撤销最近的操作并返还材料 | `PlayerWorldEdit.Use` |
| `/pwe id` | 查看手上物品的 ID(点击可复制) | `PlayerWorldEdit.Use` |
| `/pwe tool` | 给自己一把创世神镐 | `PlayerWorldEdit.Admin` |
| `/pwe reload` | 重载配置和语言文件 | `PlayerWorldEdit.Admin` |

`PlayerWorldEdit.Use` 默认所有人可用; `PlayerWorldEdit.Admin` 默认仅 OP。

### 领地保护

装了 Dominion 时, 选区里只要碰到你没有放置权限的领地就直接拒绝, 并告诉你被哪个领地拦下;
替换操作还额外需要破坏权限。

### 记录与回滚

装了 CoreProtect 时, 本插件的编辑会**带上玩家身份**写进 CoreProtect 记录, 所以即使撤销记录
被删掉, 也能用 `/co rollback` 按玩家 + 时间把改动回滚。可以在 `settings.yml` 里用
`coreprotect-logging: false` 关掉(大范围操作会因此少写几十万行记录)。

### 撤销

- 每次填充/替换都会留一条撤销记录, 存成文件: `plugins/PlayerWorldEdit/undo/<玩家UUID>/<时间戳>.json.gz`
- 操作多大都会记录, 没有体积上限
- 默认保留最近 10 条, 数量在 `settings.yml` 的 `undo-limit` 里改, 超出的旧记录自动删除

## 配置文件

- `settings.yml`: 创世神镐的名字/材质/模型数据/lore、材料背包 GUI 文案、选区粒子、撤销条数限制
- `lang/zh_CN.yml`: 所有提示文本

改完配置游戏里执行 `/pwe reload` 即可生效(创世神镐的名字/lore 改动需要重新 `/pwe tool` 领一把)。
`/pwe reload` 只重载配置, 不会碰玩家数据 —— 材料包缓存不受影响。

## 构建发行版本

发行版本用于正常使用, 不含 TabooLib 本体。

```
./gradlew build
```

## 构建开发版本

开发版本包含 TabooLib 本体, 用于开发者使用, 但不可运行。

```
./gradlew taboolibBuildApi -PDeleteCode
```

> 参数 -PDeleteCode 表示移除所有逻辑代码以减少体积。
